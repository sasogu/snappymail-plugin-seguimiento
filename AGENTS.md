# Seguimiento

Independent SnappyMail plugin. Do not modify the SnappyMail core.
Use strict PHP and the existing vanilla JavaScript/Knockout API.
Increment VERSION whenever JavaScript, CSS or templates change.
Run `php -l index.php`, `php tests/store.php`, `php tests/backend.php`,
`node --check seguimiento.js`, `node tests/ui.cjs`, and `python3 tests/demo.py`.
Only synthetic metadata may appear in screenshots, fixtures and logs.
Do not publish credentials, real mail, databases or deployment configuration.
Owner and active account must come from the authenticated session, never input.
